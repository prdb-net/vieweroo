# Vieweroo

Vieweroo is a native macOS video library and player for collections spread across local disks and mounted drives. Browse by studio or performer, collect favorites, and return to the parts of a video you watch most. Your files stay in their original folders.

## Build, test, and package

Use an Apple Silicon Mac with Xcode 16.3 or later selected as the active developer directory and a Swift 6.1 or newer toolchain. Swift Package Manager downloads the pinned GRDB dependency on the first build. The app targets macOS 14 and later.

Run these three commands from the repository root.

```sh
./scripts/build
./scripts/test
./scripts/package
```

The build produces `dist/Vieweroo.app`. The test suite uses temporary catalogs, generated video, synthetic PRDB responses, and a substitute for legacy Keychain access. Packaging rebuilds and signs the Apple Silicon app locally, then writes `dist/Vieweroo-apple-silicon.zip`.

## Run the synthetic test library

Run `./scripts/test-library --install` once on a supported Mac to install **Vieweroo Test Library** in your personal Applications folder (`~/Applications`). Setup uses Python 3 and FFmpeg with libx264 (`brew install ffmpeg`) to generate 40 short H.264 movies with audio. The app opens **Motion Archive** in its studio overview. Allow the initial scan and thumbnail generation to finish.

After setup, double-click the app in Finder or open it from Spotlight. The simulated PRDB runs inside the app and works offline. Everyday launches need only the installed app and its data in `~/Library/Application Support/net.prdb.vieweroo.test-library.installed/`. Favorites, playback positions and settings persist after quitting or restarting your Mac. To update to a newer checkout build, quit the test app and run the install command again.

Explore eight fictional publishers, including simulated OnlyFans and Fansly accounts, with five titles each and a recurring cast of 16 performers with illustrated portraits. In **All Videos**, search for **Lanterns at Dusk**, open its cast, or play another title from **More to Watch**. The clips run for 24–48 seconds so you can try seeking, resuming, muting and A–B loops.

The simulator supplies its own test key. The scanner reads each file, computes its OSHash and identifies it by hash and byte size. Studio lookup, title search and match correction use the same Swift client as the regular app. Test credentials and preferences use a dedicated defaults suite.

For an independent development library, run `./scripts/test-library` without arguments. This builds and opens a checkout-local copy with its own media and catalog in `.local/test-library/`.

## Install and update

1. Extract the ZIP and drag **Vieweroo.app** to **Applications**.
2. Open Vieweroo. The app is ad hoc signed and distributed without Apple notarization. If macOS blocks a copy that you trust, open **System Settings → Privacy & Security**, choose **Open Anyway** for Vieweroo, and confirm.
3. Enter your personal PRDB API key while online. Vieweroo validates it and saves it in a separate local settings database. One key works across all your libraries.
4. Choose **New Library**, give it a name, and open **Settings**. Click the gear beside **Source folders**, then **Add Folder…**. Once the library has a source folder, use the plus to add another. You can also press ⌘O to add a folder. The first scan imports MP4, M4V, and MOV files, including subfolders. Tiles appear as files are discovered. Click the status at the bottom of the sidebar to see the folder scan, PRDB matching and preview progress, including waiting videos, offline folders and failed previews.

To update, quit Vieweroo and replace the app in Applications with the new copy. The catalog lives in `~/Library/Application Support/net.prdb.vieweroo/`; previews live in `~/Library/Caches/net.prdb.vieweroo/`. The replacement opens the existing catalog and migrates it as needed. On the first update from a Keychain-based version, macOS may ask for access to the previous PRDB key and PIN verifier. Allow the transfer to preserve them. Vieweroo saves both in `Settings.sqlite` before removing the old items. If you cancel, choose **Try Again** when ready. Later launches and updates use the settings database.

## Browse and play

- Use the library menu at the leading edge of the title bar to switch or create libraries. Choose **Settings** at the end of the Library section in the sidebar to rename the active library, manage its source folders, or delete it.
- Press ⌘F or use the search field beside Back to search the current collection. In **Studios**, search by name, platform or @handle. Click the heart beside a studio name to save it in this library. The Filters button offers **Favorite studios** and studio groups. In a video collection, search its titles, filenames, studios, performers and tags. **Favorites** shows the videos you saved. Open **Filters** in any video collection to combine search text with quality tiers, studios and tags. Check several values in a group to include any of them. Narrow the result to favorite, liked, available or unplayed videos. **Show** applies the draft and displays its matching videos. **Cancel** discards edits. Click the × on an active filter to remove it.
- In **All Videos**, **Favorites**, **Liked** or **Watch History**, click the pencil beside **Filters** and select video tiles. **Select All** (⌘A) selects every match in the current search and filters. In All Videos, use **Add to Favorites**, **Like Videos**, **Dislike Videos**, **Add to Playlist** or **Add Tags…** directly above the grid. In Favorites or Liked, remove the current mark or use **More** to apply the other mark. In Watch History, **Remove from Watch History…** clears the selected videos’ play counts, watch time and watched segments while preserving their resume positions. **More** also lets you favorite or like those videos. Favorites, Liked and Watch History also offer **Add to Playlist** and **Add Tags…** under **More**. Click **Undo** in the confirmation to reverse the batch. **Done** returns to browsing.
- Select a video to see its cast, save a favorite, rate it, or open **Library Details** (ⓘ) beside the reactions to edit tags or confirm a suggested PRDB title. The resolution beside the studio comes from the local video track. Click **Video Encoding** for the codec, dimensions and frame rate. **Show in Finder** opens the containing folder with the file selected. Click the plus beside **New tag** or use **Choose Tag** to add a chip, and click its × to remove it. Each edit is saved immediately. The pencil beside **File** opens **Rename File…**, which changes the filename on disk and keeps its extension and library history. Under **Studio**, click the **Choose Studio…** pencil to select or create a studio. Click the × on its chip to restore automatic assignment.
- Open **Tags** under **Liked** to browse the active library’s tags by image and search by tag name. Open a tag to see its videos. Use the pencil to select videos, then **Remove Tag from Selected Videos** to remove the assignment. **Undo** restores the batch. The **Manage Tags** gear lets you create, rename or delete a tag.
- Control-click a studio, tag or playlist tile and choose **Choose Cover…**, or use the photo button in **Manage Studios**, **Manage Tags** or the playlist overview’s edit mode. Select one of its videos, use the filmstrip or slider to find a scene, then use the left and right arrows to step one frame at a time. **Use This Frame** saves the image locally so it stays visible when a drive is disconnected. **Use Automatic Cover** restores the first video’s poster for a studio. For tags and playlists, it picks an available still in assignment or playlist order.
- In **Studios**, click the **Manage Studios** gear beside Filters, then click the **New Studio…** plus to add an empty studio to this library. Filter by **OnlyFans** or **Fansly** to see creator accounts on that platform. Click a linked @handle here or on a video to open the profile in your browser. Filter by **My Studios** to see your own studios and their video counts. Click the pencil beside a studio to update its name across the library. If you delete a studio, its videos return to their automatic studio, or to **Unknown Studio** when no studio is known.
- Reopening a collection brings back its last applied search, filters and scroll position, even if it has no matches. Each studio, performer and playlist keeps its own view. Locking Vieweroo, switching libraries or quitting clears these views.
- Click **Back** or press **⌘[** to return through videos, performers, studios, playlists and searches. Back restores your search, filters and scroll position and highlights the tile you opened.
- In **Library Details**, choose **Find Match…** or **Correct Match…** to review suggestions or search PRDB. Search by title, studio or performer, alone or in combination. Select a result and click **Use Title** to save the match. Choose **Remove Match** beside the current assignment to keep this video unmatched across refreshes. Use **Find Match…** when you want to link a title again.
- **Watch History** ranks videos by how much of each movie you saw and how long you watched across visits. Each tile shows its play count and total watch time.
- Open **Playlists** in the sidebar to browse the active library’s playlists by cover image, name and video count. Click the edit pencil beside **Filters**. Use the plus to create a playlist, select one tile to rename it or choose its cover, or check several playlists and click the trash button to delete them together. **Recent Playlists** offers shortcuts to the five most recently opened lists in this library. Use **Add to Playlist** on a video. Inside a playlist, click the edit pencil, check video tiles and choose **Remove from Playlist**. **Select All** (⌘A) selects the current search and filter results. **Undo** restores the removed videos in order. To move a video earlier or later, Control-click its tile while browsing.
- In a playlist, click **Cinema Mode** to resume its first playable video in the entire window. Previous and Next follow the saved playlist order and skip unavailable videos. Use the heart or thumbs to react to the current video. The **More to Watch** list floats over the video on the right and offers other playable videos from this playlist. In **Vieweroo → Settings…** (⌘,), set **Cinema recommendations** to 2, 4 or 6 videos. The default is 4. In smaller windows, the list shows at most 4. Click a title to resume it, or toggle the sidebar button in the bottom bar to hide or show recommendations. Vieweroo remembers this setting. Press Escape to return to the playlist. In full screen, press Escape once to return to windowed Cinema Mode first.
- Move the pointer across a video thumbnail or title poster to see timestamped stills as soon as its previews are ready. Select the studio name or a cast member to explore their other videos.
- Use the Play button on a video tile to start or resume immediately. On the title page, choose **Play**, **Resume**, **Play from Beginning**, or click the play count and watch time to open **Viewing History** and play from a listed segment. Use the arrow keys to skip ten seconds, and the bracket keys to mark the start and end of a loop. Click the video or press Space to toggle playback. Use the volume slider or press M to mute. Click the full-screen button, double-click the video, or press F to enter or leave full screen. Escape leaves full screen first, then returns to the library. Use the AirPlay picker to select a video receiver. For receivers that need a network URL, Vieweroo streams the current file from your Mac. Keep both devices on the same local network and allow local network access if macOS asks. The receiver must support the movie’s video and audio formats.
- Select a title under **More to Watch** to play it at its saved position. The suggestions appear beside the video in wide layouts and below the cast in narrower windows. Back returns to the original collection, even after switching suggestions.
- Choose **Refresh Library** (⌘R) after adding or moving files. Disconnected sources and missing files retain their entries and personal data. **Source Folders** lets you see the effect of removing a source before you confirm.

## Privacy and access

PRDB receives the filename, file size, and available OSHash for identification. Folder names are evaluated on your Mac. PRDB also supplies candidate titles, artwork, studios, and cast. Ratings, tags, playlists, match corrections, and viewing history stay local.

If your subscription no longer includes API access, you can still browse and play your local library. After restoring the subscription, open the sidebar activity details and choose **Retry PRDB**. To use a different subscription, open **Vieweroo → Settings…** and click the pencil beside **PRDB API key** to enter and verify the replacement key.

Enable a PIN in **Vieweroo → Settings…** (⌘,) and press ⇧⌘L to lock the app and stop playback. **Forgot PIN?** uses macOS account authentication. PIN protection controls the interface and playback. The settings database sits alongside the catalog and is readable and writable only by your macOS user by default. Anyone with a copy of that file or its backup can read the API key. It contains a salted PIN verifier. The catalog and image cache use ordinary local storage.
